# TinyPl0 Requirements

## Struktur / Structure

- `baseline/`: unveränderliche historische Pflichtenhefte
- `intakes/active/`: aktuell prüfbare Anforderungen
- `intakes/archive/`: abgeschlossene branch-suffigierte Intakes
- `intakes/history/`: ersetzte Intakes, Reihenfolgen und Receipts
- `intakes/backlog/`: optionale oder zurückgestellte Anforderungen
- `intakes/series/`: Reihenfolge, Abhängigkeiten und Review-Evidence
- `traceability/`: Regeln für Quellen- und Anforderungsnachweise

*The directories separate immutable baselines, active work, completed work,
superseded evidence, optional backlog, executable ordering, and traceability.*
